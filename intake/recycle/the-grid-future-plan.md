# THE GRID Future Plan

Status: Concept phase. Not current build target.

Build after:

- Pachinko Bounce ships
- Supabase is stable
- JARVIS is mature

## What The Grid Is

The Grid is a personal navigable information space built on top of JARVIS memory and knowledge infrastructure.

It is not a virtual world simulation. It is a structured semantic space that becomes navigable as hardware and interfaces mature.

## Core Concept

Personal Grid:

- personal compiled knowledge space
- governed by JARVIS
- built from data the user pushes, not data harvested from the user
- structured by sessions, decisions, memory, and knowledge relationships

Public Grids:

- shared spaces people opt into
- communities, markets, hubs
- cooperative ownership model
- sustainable economics, with Log Horizon as a reference point

## Technical Foundation

Knowledge graphs:

- Neo4j or GBrain graph layer
- typed relationships between concepts
- partially foreshadowed by the JARVIS interaction graph

Vector databases:

- semantic similarity retrieval
- already present in the MNEMOS vector layer
- local `nomic-embed-text` support

Spatial interface:

- depends on AR/VR hardware timeline
- Godot 4.x can support spatial prototypes now
- consumer-accessible full spatial hardware remains later-stage

NLP navigation:

- user describes where they want to go
- AYRE extracts intent
- ODIN routes through the graph

## VIRGIL Function

JARVIS acts as guide through the Grid.

It knows the territory, surfaces relevant memories, and routes the user through their own compiled knowledge.

## Visual Layer

Near-term:

- text adventure with images
- AI-generated images for location rendering
- buildable with current image generation APIs

Long-term:

- full spatial interface waits on hardware
- Godot 4.x spatial prototype can explore the interaction model before AR/VR is ready

## ERIS In The Grid

ERIS monitors alignment as the space grows.

Gold Law #7 applies to the Grid itself: no expansion without simplification.

ERIS prevents complexity from accumulating without purpose.

## Honest Timeline

- Personal Grid data layer: buildable now with Supabase and GBrain
- Text and image navigation: buildable in 1-2 years
- AR overlay interface: 3-5 years
- Full spatial environment: 5-10 years

## Build Order When Ready

1. GBrain knowledge graph as Grid foundation
2. Query interface with text-based navigation first
3. Image generation layer for location rendering
4. Godot 4.x spatial prototype
5. AR integration when hardware is ready

## Reference Points

- Log Horizon: governance and cooperative economics
- Gun Gale Online: real-world monetary integration
- Tron: aesthetic and spatial navigation feel
- Battle Network: layered digital space alongside physical space
