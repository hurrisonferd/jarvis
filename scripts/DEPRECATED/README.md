# DEPRECATED — Replaced by Better Solutions

**Status:** Intentionally replaced, do not use

**Criteria:**
- Has been superseded by a better implementation
- Contains patterns that were wrong or suboptimal
- Was the active version but has been replaced
- May still work but should not be deployed

**What goes here:**
- Old active scripts replaced by newer versions
- First attempts that were improved
- Scripts with known issues that were solved elsewhere

**What goes in ARCHIVED vs DEPRECATED:**
- ARCHIVED = might be useful for reference/patterns
- DEPRECATED = was actively used, now replaced (lineage important)

**What to do:**
- Move here when you replace an active script
- Add a note in the file header explaining why
- Include a link to what replaced it
- Keep for lineage/audit trail
