## What is GRID?

GRID is a sovereign federated node architecture for human-AI cooperation. Each person owns their node. Connection is consensual. Intelligence is distributed. No central authority.

## Core Principles

1. **Sovereignty** — Each node belongs to one person. They control it completely.
2. **Consent** — Connection between nodes is by explicit agreement.
3. **Distribution** — Intelligence lives at the edges, not in a central system.
4. **Cooperation** — Nodes can share, collaborate, and build together.
5. **Exit** — Any node can leave at any time.
