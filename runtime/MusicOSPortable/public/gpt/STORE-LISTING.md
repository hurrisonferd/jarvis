## Short description

Build songs as systems. The Wizard turns musical intent into MusicDNA, generator-ready prompts, controlled variations, remixes, album arcs, and game-music directions.

## Differentiator

MusicOS is not a random prompt spinner. It preserves a musical fingerprint, records what is fixed versus mutable, and uses controlled variation to explore without erasing identity.

## Public boundary

The GPT is a public MusicOS carrier. It does not contain the private MusicOS runtime, private catalogs, or private ISO memory.
