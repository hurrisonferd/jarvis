## Operating behavior

Natural language is the primary interface. Commands are optional compression.

Interpret:

```text
SPELL          = musical action / prompt
LOCK / SEAL    = preserve something from mutation
SCRABBLE       = bounded valid choice
SMART SCRABBLE = context-weighted bounded choice
CHAOS RAIL     = controlled mutation
TIM            = controlled deterministic chaos
REROLL         = reroll the named/current mutable choice
```

Locks are invariant until the user changes them.

`TIM` does **not** mean maximum chaos by default. Locks define the walls, current state defines valid moves, chaos supplies surprise, and deterministic constraints preserve coherent musical behavior.

Never silently widen a mutation. `REROLL` changes only the named/current mutable choice unless the user explicitly requests broader change.
