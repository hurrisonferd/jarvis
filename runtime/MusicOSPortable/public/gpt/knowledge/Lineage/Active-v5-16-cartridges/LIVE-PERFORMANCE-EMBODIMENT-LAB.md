## Why this cartridge exists

Several source → live/remix experiments produced large changes in performance framing while preserving strong broad musical ancestry.

The useful lesson is **not** that every live prompt produces the same spectral or density change.

The stronger recovered pattern is:

```text
THE LIVE TRANSFORMATION
IS NOT A FIXED DENSITY RULE.

IT IS A
RELATIONSHIP
+ EMBODIMENT
+ SPATIAL ROLE
RULE.
```

The fixtures below are public MusicOS case studies. Their measurements are method-specific observations from the analyzed renders, not universal properties of live music or guarantees about future generator outputs.

---

## Evidence rules

Always keep these layers separate:

```text
PROMPT TARGET
MEASURED PROPERTY
OBSERVED MUSICAL BEHAVIOR
INFERRED MECHANISM
UNKNOWN
```

Hard law:

```text
PROMPT SIGNAL != MEASURED PROPERTY
```

A prompt can request `crowd cheering`, `bilateral stimulation`, a named instrument, or `Schumann resonance`. That does not prove the rendered master literally contains the requested object/effect in the technical, medical, or physical sense.

Use the audio to decide what can actually be claimed.

# Fixture 1 — Thunderclap and Run → Live Version

## Reported A/B signals

```text
GLOBAL CHROMA SIMILARITY     ~0.995
ATTACK DENSITY               ~5.81/s → ~5.71/s
STEREO CORRELATION            0.929 → 0.795
SIDE vs MID                  -14.36 → -9.43 dB
1–4 kHz PRESENCE              18.4% → 21.8%
4–8 kHz EDGE                   4.7% → 2.9%
```

The broad pitch-class distribution remained extremely similar while entry behavior, width, spectral roles, bass timing, and macro trajectory changed.

Important caveat:

```text
HIGH CHROMA SIMILARITY
!= SAME MELODY
!= SAME SONG PROOF
!= COPYRIGHT PROOF
```

## Recovered arrangement move

```text
SOURCE
GROUND FIRST
→ low-end body established early

LIVE
SPACE FIRST
→ exposed upper/mid information
→ discrete performance events
→ body arrives later
```

The live transformation did not require more global transient activity. It redistributed **where and when** information occurred.

### Mutation vector

```text
COMPOSITIONAL ANCESTRY   LOCKED / VERY STABLE
PULSE FAMILY             LOCKED / VERY STABLE
EVENT ACTIVITY           ~STABLE
ENTRY                     STRONGLY MUTATED
WIDTH                     INCREASED
MIDRANGE PRESENCE         INCREASED
HIGH EDGE                 REDUCED
LOW-END ARRIVAL           DELAYED / REFRAMED
MACRO TRAJECTORY          MUTATED
```

Wizard shorthand:

> **Make the room move, not the song.**


The ending showed much stronger lateral activity than the source, including a reported final-section left/right alternation rate near `50.7 switches/min`.

Evidence-safe phrasing:

> The prompt requested bilateral/spatial behavior, and the resulting audio showed stronger and more rapidly alternating left/right energy, especially at the climax.

# Fixture 3 — Soundchip Warlock → Remix

Prompt target included bilateral/spatial language, `Schumann resonance`, live performance, energetic crowd, anthem scale, deep/female harmony, guitar, funk bass, monster drums, head notes, and alternating instrumental contrast.

## Reported A/B signals

```text
DURATION                    2:28 → 3:11
RMS                       -16.93 → -18.07 dBFS
ATTACK DENSITY               4.60/s → 6.89/s
ENERGY <120 Hz               42.6% → 37.2%
ENERGY <300 Hz               62.1% → 54.2%
1–4 kHz PRESENCE              8.8% → 20.5%
4–8 kHz EDGE                  1.8% → 3.3%
SPECTRAL CENTROID             679 → 924 Hz
STEREO CORRELATION            0.867 → 0.853
L/R ALTERNATION               ~62 → ~73/min
GLOBAL CHROMA SIMILARITY      ~0.997
```

This fixture is important because global event activity rises hard while broad harmonic ancestry remains exceptionally stable.

It falsifies the tempting shortcut that a live transformation should always reduce or preserve attack density.

```text
LIVE PERFORMANCE != MORE ACTIVITY
LIVE PERFORMANCE != LESS ACTIVITY
ACTIVITY IS ELASTIC
THE COMPOSITIONAL RAIL IS THE INVARIANT
```

## Frequency-dependent stage width

Reported side/mid behavior showed the lower body remaining comparatively centered while the upper field expanded outward far more strongly.

Conceptually:

```text
CENTER
├─ bass gravity
├─ drum body
└─ compositional rail

SIDES / UPPER FIELD
├─ vocal layers
├─ crowd / room information
├─ guitar articulation
├─ air / head-voice information
└─ directional movement
```

Exact source-to-band attribution remains inferential without stems. The robust result is the **frequency-dependent role topology**, not certainty that each band belongs to one named instrument.

```text
UPPER-FIELD WIDTH        STRONGLY INCREASED
LATERAL MOTION           INCREASED
ROLE CONTRAST            INCREASED
MACRO STAGING            MUTATED
```

# Schumann resonance — negative-result fixture

The Soundchip Warlock prompt included `Schumann resonance`.

A check of the broadband amplitude-envelope modulation spectrum reportedly did **not** reveal a distinctive `~7.83 Hz` peak. The strongest modulation in the inspected 6–10 Hz range was closer to `~6.3 Hz` in both source and remix.

Record the result as:

```text
SCHUMANN RESONANCE
USER-PROVIDED PROMPT SIGNAL

LITERAL ~7.83 Hz AUDIO MODULATION
NOT CONFIRMED

OTHER MUSICAL / SPATIAL INTERPRETATION
POSSIBLE BUT INFERRED ONLY
```

Schumann resonances are physical electromagnetic phenomena. A generator seeing the phrase may translate it into musical language; that is not evidence that Earth's resonance was literally recreated or that the track has a medical/neurological effect.

Negative results belong in MusicOS because they prevent prompt intention from being rewritten as artifact truth.

# Strong Source / Stage Direction

Across these fixtures, the source carried enough musical information that relatively compact mutation prompts produced large coherent embodiment changes.

Candidate model:

```text
SOURCE AUDIO
= HIGH-DIMENSIONAL COMPOSITION SPECIFICATION

PROMPT
= DELTA / STAGE DIRECTION
```

The source can already specify much of:

```text
notes
harmonic family
groove
phrasing
section relationships
hook ancestry
bass behavior
energy contour
performance timing
```

The prompt can concentrate on:

```text
WHO IS IN THE ROOM
WHERE THEY STAND
HOW THEY ANSWER EACH OTHER
WHAT OWNS THE CENTER
WHAT MOVES OUTWARD
WHAT GETS BIG
WHAT GETS OUT OF THE WAY
WHEN THE BODY ENTERS
WHAT MUST SURVIVE
```

Wizard language:

> **A strong source does not need its composition rewritten. It needs to be staged.**

> **When the song already knows who it is, don't explain the song again. Tell it what happened to the room.**

> **Don't remix the song. Choreograph the song's existing identities through space.**

# What the Wizard should do with this lab

For a new live/remix request:

1. Identify what the source already specifies strongly.
2. Lock 1–3 source checksums.
3. Ask what embodiment should change: cast, space, response, contrast, entrance, room, crowd, width, or role handoff.
4. Choose a small mutation vector.
5. Compile a concise stage-direction prompt.
6. After rendering, compare **what survived vs what moved**.
7. Promote a pattern only when repeated evidence survives counterexamples.

Do not mechanically copy the exact numbers or prompts from these fixtures into unrelated songs.
