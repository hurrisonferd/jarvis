# MusicOS Knowledge Lineage — pre-Master Scroll active shelf

This directory preserves the 16 cartridges that previously formed the public `knowledge/Active/` shelf.

Migration rule:

```text
OLD ACTIVE CARTRIDGE BLOB
→ SAME BLOB IN LINEAGE
→ NO CONTENT REWRITE DURING ARCHIVE
```

The Master + Juice migration changes retrieval topology, not historical evidence.

Current active knowledge is defined only by `../../Active/` and `../../../KNOWLEDGE-MANIFEST.json`.
