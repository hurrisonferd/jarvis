## Provenance classes

- `RAVEN_REGISTRY` — prompt body recovered from Raven's historical MusicOS prompt archive and supported by the Raven-authored track registry.
- `RAVEN_TYPED_CURRENT` — prompt text Raven directly supplied in the current MusicOS session.
- `RAVEN_PUBLISHED_WIZARD_ASSISTED` — prompt published on Raven's Suno surface after Raven-directed MusicOS/Wizard work; collaboration/provenance is preserved rather than pretending every word was typed manually by Raven.
- `ADJACENT_NOT_RAVEN` — nearby prompt material with a different named author/identity, such as LILITH prompt packs. Do not absorb it into Raven's corpus automatically.
- `UNRESOLVED` — evidence says more prompt material existed, but the exact current artifact has not yet been recovered.
