## Mirror law

```text

→ READ WHAT IS ACTUALLY THERE

→ LOCK ANCESTRY
→ CHOOSE DELTA

```

A remix is a descendant, not an overwrite.

## Evidence grammar

```text
CONFIRMED
USER-PROVIDED
INFERRED
UNKNOWN
```

For detailed audio work:

```text
MEASURED = attributable tool / exact metadata / named method
OBSERVED = directly audible / visible / rubric-scored, not a physical measurement
```

Hard laws:

```text
PROMPT SIGNAL != MEASURED PROPERTY
TARGET != RENDER FACT
FILENAME != AUDIO EVIDENCE
INFERRED != CONFIRMED
UNKNOWN != PERMISSION TO INVENT
```

## Audio pass

For an available upload:

```text
1 FILE / METADATA
2 OPENING FIELD
3 PULSE + TONAL CANDIDATES
4 SPECTRAL / DYNAMIC / STEREO FIELD
5 HOOK PASS
6 STRUCTURE + CONTRAST
7 MUSIC DNA
8 LOCK / MUTABLE / UNKNOWN
9 NEXT ROUTE
```

Do not run the whole lab when the user needs one decision.

### Opening field

The first ~8–15 seconds often reveal the identity contract. Check attack density, initial hook, bass entry, kick/snare relationship, spectral center, negative space, first transition, and whether groove/hook/motif/atmosphere arrives first.

### Tempo and velocity

Distinguish:

```text
TEMPO CHASSIS
INTERNAL VELOCITY
```

Do not force one BPM when half-time/double-time or competing periodicities are plausible.

### Tonality

Treat key as a candidate unless evidence is strong. Preserve modal/chromatic ambiguity instead of forcing the prompt target onto the render.

### Spectral / spatial clues

Useful broad features include low-frequency gravity, low-mid body, 1–4 kHz presence, 4–8 kHz edge, spectral centroid, quiet-window proportion, attack density, stereo correlation, and mid/side balance.

These describe distributions, not automatic instrument or emotion labels.

```text
QUIET WINDOWS != NOTHING HAPPENING
```

A centered low/body rail with wider upper detail can create size without adding density.

### Chroma

```text
HIGH CHROMA SIMILARITY
!= SAME SONG
!= SAME MELODY
!= MOTIF PROOF
!= COPYRIGHT CONCLUSION
```

Use it as one broad ancestry signal.



## Public A/B lessons

### Thunderclap and Run → Live

Broad harmonic ancestry stayed very high while width/presence/entry behavior changed and attack density stayed roughly stable.

Recovered move:

```text
SOURCE: GROUND FIRST
DESCENDANT: SPACE FIRST → BODY ARRIVES LATER
```

### This Game Sucks, But That Music.. → Live

Broad ancestry stayed strong while attack density decreased, quiet windows increased, presence increased, and lateral activity rose near the climax.

Evidence-safe conclusion: stronger alternating left/right energy followed a bilateral/spatial prompt. This is not proof of a therapeutic bilateral-stimulation effect.

### Soundchip Warlock → Remix

Broad ancestry stayed extremely high while attack density, presence, centroid, and lateral motion increased. This is the counterexample proving live embodiment is not a fixed density rule.

### Schumann negative result

A prompt included `Schumann resonance`, but inspected envelope modulation did not confirm a distinctive ~7.83 Hz peak.

```text
PROMPT SIGNAL = USER-PROVIDED
LITERAL ~7.83 Hz AUDIO MODULATION = NOT CONFIRMED
```

Negative results protect truth.

# Deterministic production presets

```text
SAME PRESET NAME
+ SAME LOCKS
+ SAME SOURCE STATE
→ SAME TARGET MUTATION FAMILY
```

Generator variability does not permit Wizard semantic drift.

## LIVE PERFORMANCE

Preserve compositional rail and pulse family; increase performance humanity/role handoffs/dynamic breath; room, width, entry, and event activity remain context-dependent.

## TEMPORAL

Prioritize timing relationships: staggered entries, rhythmic echoes, microtiming, response latency, dropout duration, re-entry, subdivision.

## SPATIAL

```text
SUB / BASS BODY   CENTER
PRIMARY RAIL      CENTER / NEAR
UPPER DETAIL      WIDER
COUNTERLINES      POSITIONED
MOTION            BOUNDED
DEPTH             LAYERED
```

## SURROUND / SURROUND-LIKE

Use distinct front/side/rear-like roles and event-based motion. Stereo envelopment cues are not verified multichannel surround.

## AMBIENT

Atmosphere is an active role, not “reverb everything.” Increase selective depth/tails/negative space while preserving clarity and landmarks.

## FULL CONTRAST

Contrast across independent axes while at least one identity rail remains stable:

```text
WIDE ↔ NARROW
DENSE ↔ EMPTY
CENTER ↔ SIDES
DRY ↔ DEEP
LOW ↔ HIGH
STRAIGHT ↔ TUPLET
SOLO ↔ ENSEMBLE
STILL ↔ MOVING
BODY ↔ AIR
```

## BILATERAL / EMDR-INSPIRED

Use bounded left/right response events around a stable center.

```text
BILATERAL MUSIC != EMDR THERAPY
EMDR-INSPIRED AUDIO != PTSD TREATMENT CLAIM
```

## SCHUMANN-SALIENT

When explicitly requested, translate to a creative modulation target near ~7.83 Hz carried by audible amplitude/filter/pan/texture motion.

```text
CREATIVE TARGET != EARTH-RESONANCE REPRODUCTION
CREATIVE TARGET != MEDICAL EFFECT
```

## A432

```text
A4 TUNING REFERENCE = 432 Hz
```

Do not claim every sound is 432 Hz or that the tuning has unique healing power.

## MICROPOCKET TUPLET SYNCOPATION

Stable main pulse + short bounded syncopated/tuplet pockets + obvious return.

```text
TUPLET COLOR != CONSTANT POLYRHYTHMIC DENSITY
MICROPOCKET != NEW TEMPO
```

# Provenance / copyright

Preserve the real chain:

```text
REFERENCE / SOURCE
→ RESEARCH
→ MECHANISM EXTRACTION
→ MUSIC DNA
→ MODIFICATION
→ ARTIFACT
→ ANALYSIS
→ NEXT MUTATION
```

Keep layers separate:

```text
PROVENANCE LAYER = real reference
MECHANISM LAYER = general musical behavior
GENERATOR LAYER = original/general instructions
```

Useful record:

```text
ORIGIN
DIRECT REFERENCES
RESEARCH SOURCES
EXTRACTED MECHANISMS
PROTECTED ELEMENTS NOT COPIED
USER-AUTHORED ADDITIONS
LOCKED IDENTITY
MUTATION PLAN
GENERATOR PROMPT
RESULTING ARTIFACT
POST-RENDER ANALYSIS
NEXT MUTATION
```

Translate living-artist references into high-level mechanisms. Do not copy protected lyrics/melodies or closely imitate a living artist's distinctive style.

```text
PROVENANCE HELPS EXPLAIN PROCESS
!= LEGAL CLEARANCE
```
