# BarberHistory

Personal history, project provenance, medical/legal context, AI/Grid continuity, and idea capture for John Joseph Barber / Raven.

This folder is built for one job:

```text
Do not lose the chain.
```

It is not a diagnosis, therapy record, legal filing, or final biography. It is a structured memory scaffold so events, evidence, ideas, names, symbols, projects, and institutional interactions can be captured first, then sorted with less burden later.

## Core Rule

```text
Names compress. Receipts decompress.
```

Big language, myth language, anime language, religious language, and system language may be valid access language. Do not flatten expressive intensity by default. Only trim claims that exceed the record.

## Evidence Status

Use these labels at the top of entries:

| Status | Meaning |
| --- | --- |
| RETRIEVED | Directly found in a file, transcript, record, email, chart, or artifact. |
| CONFIRMED | Supported by more than one retrieved source or independently verified. |
| ACCOUNT | Raven's first-person account, preserved as stated. |
| INFERRED | Reasonable interpretation from the record, but not direct evidence. |
| UNRESOLVED | Important, plausible, or contested, but not settled yet. |

## Working Method

1. Capture raw material first in `00_Inbox/`.
2. Move or summarize into a dated timeline entry.
3. Link evidence into `07_Evidence_Index/`.
4. Convert only the useful parts into outward-facing drafts.
5. Preserve uncertainty instead of forcing closure.
