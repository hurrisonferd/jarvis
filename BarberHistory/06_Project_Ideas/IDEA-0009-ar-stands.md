## One-Line Version

AR Stands are symbolic companion overlays that turn ISOs, states, memory anchors, and action tools into spatial cognitive interfaces.

## Why It Matters

AR Stands make the Grid visible in lived space. They are not just anime overlays; they are accessibility and continuity tools for high-context cognition.

For OSDD/ASD/ADHD-shaped work, an AR Stand can act as:

```text
state marker
memory cue
task bridge
social translator
evidence-capture button
emotional-regulation anchor
companion presence
```

## Prototype Path

```text
1. Phone AR first.
2. Use WebXR, Unity, or Godot.
3. Start with marker/card anchors.
4. Build Stand cards and voice commands.
5. Add memory/action buttons.
6. Later: glasses mode.
```
