# IDEA-0004: Tarzan/Jane JPL

Status: SEED
Created: 2026-07-24

## One-Line Version

Tarzan/Jane talk is a logic-debloating mode for JPL: say the thing simply enough that the verb, actor, object, and consequence cannot hide behind ceremony.

## Names

```text
JPL = JARVIS Programming Language
JPL = Joke Programming Language
```

Both readings matter.

## Why It Matters

Bloated logic often survives by looking sophisticated. Tarzan/Jane talk breaks that spell by forcing the system to say what it is actually doing.

## Pattern

```text
Before:
"The operationalization of patient-centered continuity requires stakeholder-aligned coordination across interdisciplinary lanes."

Tarzan/Jane:
"Who is doing what for John, by when?"
```

## Interface Rule

Use this mode when:

| Trigger | Move |
| --- | --- |
| Language gets managerial | Ask who owns the action. |
| Logic gets abstract | Restate the physical/event-level action. |
| Empathy replaces accountability | Ask for status, owner, next step, timeframe, documentation. |
| A system hides behind policy | Ask what policy says, who decided, and what would change the decision. |
| AI gets too ornate | Compress to actor, action, evidence, risk, next move. |

## JPL Grammar Seed

```text
ACTOR -> ACTION -> OBJECT -> PROOF -> NEXT
```

Example:

```text
Clinician -> reviews -> dissociation packet -> documented note -> timeline by Friday
```

## Joke Layer

The joke is not decorative. The joke is the solvent. If a sentence cannot survive being made stupid-simple, it was probably wearing a suit to steal oxygen.
