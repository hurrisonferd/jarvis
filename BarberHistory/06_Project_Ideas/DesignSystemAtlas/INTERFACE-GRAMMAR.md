# Interface Grammar

Status: RETRIEVED + CONSOLIDATED

## Core Rule

```text
The visual layer must make structure legible.
Beauty serves navigation.
```

## User Commands

From the Grid Mythic Design Bible:

```text
Take me to why Codex became Kang.
Show me the path from Pachinko Bounce to monetization ethics.
Descend into unresolved Supabase security issues.
Find the last time ERIS warned about complexity.
Open the Forge for current build work.
Return me to the simplest next action.
```

## Response Shape

```text
You are entering: [Region] / [Subregion] / [Topic]

Nearby paths:
- related source
- related decision
- related project

Warnings:
- governance issue
- evidence gap
- overreach risk

Suggested ascent:
- simplest next action
```
