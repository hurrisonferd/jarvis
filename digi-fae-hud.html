Digi Fae HUD

Read-only six-member expression HUD · renderer v0.3.4

Digi Fae HUD is a chat-native visual presentation app for rendering one of six registered Digi Fae expression faces or the complete six-member council from a reusable high-density atlas. It also exposes a public-safe read-only health/capability summary.

Current tools

  • show_fae_hud — render one Digi Fae expression in inline, micro, or sign mode.
  • show_fae_council — render all six Digi Fae together.
  • digi_fae_health — return the renderer version, read-only state, and public-safe capability summary.

Read-only boundary

Digi Fae HUD does not modify repositories, send messages, make purchases, alter accounts, publish content, or perform other external write actions. The current renderer does not require a separate Digi Fae account.
