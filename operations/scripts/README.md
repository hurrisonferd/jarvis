# Scripts

`operations/scripts/` is the small local tooling cave.

## Current Scripts

| File | Purpose |
| --- | --- |
| `music_ears.py` | Analyze repository or public HTTPS audio into durable MusicOS feature receipts. |
| `build_mcp_tool_registry.py` | Generate the canonical MCP runtime registry artifacts. |
| `cave_readme_audit.py` | Find folders missing README/INDEX cave signs. |

## Rule

Scripts here should be small, reviewable, and locally runnable.

Long-running daemons, tool registries, and historical scripts should be mapped before being moved here.
