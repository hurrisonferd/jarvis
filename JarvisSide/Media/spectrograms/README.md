# Spectrograms (the ears\047 vision bridge)

Mel-spectrogram PNGs, one per audio track, generated by scripts/audio_ears.py in the
Ears CI workflow. jarvis_media_view shows them to a vision stream so Jarvis/Ayre SEE
the shape of a song (build/drop/density) — perception of sound, not hearing it.

Auto-populated on the next audio-ears run; safe to leave empty until then.
