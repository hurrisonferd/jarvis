## Variants

| Variant | Framework | Status |
|---------|-----------|--------|
| pong-canvas | Vanilla JS + Canvas | ✅ Working |

## Controls
- **Keyboard**: W/S or Arrow keys
- **Touch**: Drag anywhere on screen, paddle follows finger (FF-style)
