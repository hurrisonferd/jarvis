# JarvisSide — Peripheral Work

Everything peripheral to the canonical core lives here. Projects, ideas, breakthroughs,
media registry, and archive. Not governed by Yggdrasil — but linked from it.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `Projects/` | Active projects (Pachinko Bounce, CodeOS, FLAG-01) |
| `Ideas/` | Proposed but not yet active |
| `Breakthroughs/` | Significant discoveries or decisions |
| `Archive/` | Completed or deprecated work |
| `Media/` | Audio, images, MusicOS registry |
