## Classification questions

1. Is the project required by JARVIS at runtime?
2. Does a hosted page, workflow, script, or import depend on its current path?
3. Is it an active implementation, design history, or duplicate export?
4. Does it contain private data, credentials, ROMs, copyrighted assets, or third-party identifiers?
5. Which README should become its public entrance?

No project receives a new canonical route until these questions are answered and recorded in the migration ledger.
