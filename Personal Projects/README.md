# Personal Projects

Independent creative and technical work that is public, useful, and not part of the core JARVIS product.

## What belongs here

- games and interactive experiments;
- music tools and creative systems;
- websites and prototypes;
- standalone utilities;
- design studies;
- historical projects worth preserving.

Each project should state:

```text
STATUS
PURPOSE
HOW TO RUN OR VIEW IT
DEPENDENCIES
LICENSE OR USAGE BOUNDARY
SECURITY / PRIVACY NOTES
LAST REVIEWED DATE
```

Recommended status values:

```text
ACTIVE
MAINTAINED
EXPERIMENTAL
HISTORICAL
ARCHIVED
```
