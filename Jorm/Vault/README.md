# Jorm Vault

Canonical continuity intake for Raven/John and JORM.

## Purpose

This vault receives chat-bound project exports and tracks them from raw source through verified canon.

## Required flow

```text
raw source
→ verbatim preservation
→ structured extraction
→ canonical placement
→ source-to-canon coverage ledger
→ continuity receipt
```

## Status rule

A paste, transcript, or dump is **RAW**, not complete canon.

Nothing may be called preserved, complete, migrated, or recovered until the coverage ledger identifies:

- source;
- recovered material;
- canonical destination;
- status: raw / processed / missing;
- unresolved edge;
- commit or verification receipt.

## Directories

- `Inbox/raw-chat-exports/` — untouched chat exports and pasted source material
- `Sources/MusicOS/` — MusicOS source captures
- `Sources/BootOS/` — BootOS source captures
- `Sources/Other/` — other project source captures
- `Canon/` — structured canonical outputs
- `Recovery_Ledgers/` — source-to-canon coverage ledgers
- `Receipts/` — commit, validation, and continuity receipts
