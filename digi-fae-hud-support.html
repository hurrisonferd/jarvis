Digi Fae HUD — Support

Digi Fae HUD is a read-only ChatGPT presentation app for rendering the six-member Digi Fae expression HUD.

Public support channel:
Open a GitHub issue

What to include

  • What you asked Digi Fae HUD to render.
  • Which member/expression was involved.
  • Whether the issue involved a single Fae, deterministic fallback, or the six-member council.
  • A screenshot if the problem is visual and you are comfortable sharing it publicly.

Please do not post

Do not include passwords, API keys, authentication tokens, payment information, private conversation exports, or other secrets in a public issue.

Scope

This support page covers Digi Fae HUD’s public app/widget behavior. It does not provide access to private RavenOS continuity, private repositories, credentials, or operational Grid state.
