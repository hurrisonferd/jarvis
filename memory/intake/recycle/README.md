# Recycle

Use this folder for reviewed, reusable material extracted from AI intake.

Good candidates:

- stable prompts
- architecture decisions
- workflow patterns
- reusable code snippets
- policy notes
- model-specific lessons

Do not put raw chat transcripts, secrets, private logs, or unreviewed agent output here.

Recommended filename format:

```text
2026-05-24_reusable-supabase-rls-policy.md
2026-05-24_codex-review-checklist.md
```
