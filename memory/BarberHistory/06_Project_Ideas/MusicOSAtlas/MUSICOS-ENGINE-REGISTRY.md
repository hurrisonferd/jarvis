## Purpose

This registry separates **specialist AIs**, **engines**, **laws**, and **runtime tools** so MusicOS is not flattened into one undifferentiated list.

MusicOS is treated as a human-in-the-loop musical cognition environment:

```text
Raven intent and lived context
-> specialist interpretation
-> engine-level transformation
-> metrics and artifact feedback
-> Raven correction and selection
-> new MusicOS state
```

An engine is not merely a named AI. An engine coordinates multiple specialists, constraints, transformation rules, and artifact states across a repeatable process.

## Recovery labels

- `CONFIRMED` — directly supported by retrieved repository evidence.
- `ACCOUNT` — directly supplied by Raven and consistent with recovered evidence.
- `INFERRED` — reconstruction supported by multiple signals but not yet proven from a primary specification.
- `PARTIAL` — real evidence exists, but the full contract is missing.
- `UNKNOWN` — named or strongly indicated, but not yet recovered.
