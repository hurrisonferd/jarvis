## JNL

JNL is the address language.

Canonical short form:

```text
DOMAIN-SYSTEM-TYPE-LOG
```

Example:

```text
ARCH-JFS-CORE-0001
```

Full form:

```text
DOMAIN-SYSTEM-TYPE-LOG-PATCH-BLOCK
```

Example:

```text
GS-ODN-RT-0001-P005-B002
```

JNL is designed to remain stable even if a file moves. JMS moves pointers; identity stays.
