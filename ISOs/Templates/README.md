# ISO Templates

This catalog is for public-safe, copyable identity-system templates. It does not contain Raven's private ISOs or operational crew memory.

## Planned tiers

| Tier | Purpose | Status |
|---|---|---|
| Minimal | Small identity, values, boundaries, and state scaffold | DESIGNING |
| Standard | Adds provenance, memory tiers, contradiction handling, and receipts | DESIGNING |
| Advanced | Adds validators, migration law, rollback, and carrier-switch checks | DESIGNING |

## Template requirements

Every template must:

- use fictional or clearly synthetic example data;
- separate identity, voice, values, boundaries, state, memory, and provenance;
- explain which fields are authoritative and which are examples;
- provide validation and reset instructions;
- avoid claims of sentience, consciousness, or autonomous authority;
- include a privacy checklist before users add personal data;
- provide a deletion/export path for locally stored information.

## Publication rule

A template is not released as ready merely because its folder exists. It requires documentation, fixtures, validation, privacy review, and a versioned release note.
