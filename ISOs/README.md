# ISOs

**Reusable, inspectable templates for building file-backed AI identities.**

This room is for public templates, schemas, validators, examples, and educational material. It is not a mirror of private crew identities.

## Start here

1. Read `START-HERE.md` when available.
2. Choose a Minimal, Standard, or Advanced template.
3. Replace all example identity data.
4. Run the validators.
5. Review privacy, provenance, correction, and rollback rules before deployment.

## What an ISO should make explicit

- identity and purpose;
- voice and stylistic boundaries;
- values and non-negotiable constraints;
- relationships and authority;
- mutable state versus durable identity;
- memory classes and retention;
- provenance and source attribution;
- correction, contradiction, and rollback procedures;
- privacy and publication boundaries.

## Safety boundary

Public examples must use fictional or sanitized data. Do not publish private transcripts, credentials, raw personal memory, private relationship details, or identifying data without deliberate review.
