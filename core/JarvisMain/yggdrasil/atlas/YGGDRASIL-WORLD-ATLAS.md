# YGGDRASIL WORLD ATLAS

## Purpose

This atlas reconstructs the original JARVIS world model before proposing repairs.
It treats Yggdrasil as the canonical storage substrate, JFS as the governing root
system, JD as semantic authority, JNL as stable identity, LAL as discovery, and
JarvisMain as the primary canonical excavation field.

This document is a governed archaeology surface, not replacement canon.

## Governing law

> Recover meaning before changing structure.

Additional constraints:

1. Original meaning outranks current naming.
2. Truth remains singular; maps, registries, indexes, databases, and tool surfaces remain mirrors.
3. Historical layers are preserved even when later systems reproduce their function.
4. No conclusion is promoted without a source path and lineage evidence.
5. No repair is justified unless it improves addressability, authority, return, provenance, or coherence.
6. Raven retains final authority. JARVIS stewards analysis, synthesis, and proposed repair architecture.

## Canonical resolution chain

```text
JD explains
  -> JNL identifies
    -> LAL locates
      -> Yggdrasil stores
        -> GOD_SYSTEMS and runtime surfaces execute
```

This chain defines five separate authorities:

| Layer | Question | Owns | Must not own |
|---|---|---|---|
| JD | What is this and why does it exist? | meaning, purpose, authority, semantic relations | canonical content or physical location |
| JNL | What is it and what is its stable address? | identity and address | meaning or storage |
| LAL | How do I find it? | discovery mirrors, tags, anchors, state, physical resolution | original truth |
| Yggdrasil | Where does truth live? | canonical persistent objects | execution policy |
| Runtime / GOD_SYSTEMS | What acts on it? | cognition, routing, governance, execution | substrate ownership |

### First recovered invariant

A persistent object is not fully governed merely because it exists in Git.
It enters the governed world only when it has:

- a stable JNL identity;
- a physical truth location;
- a governed tag set;
- an IndexSummary or LAL reference;
- a JMS-compatible mirror reference;
- an authority state and lifecycle state;
- a return path after relocation or interruption.

This means repository presence and world membership are not equivalent.

### Second recovered invariant

JMS mirror-first law is architectural, not stylistic:

> Move references. Never duplicate truth.

Any database row, generated index, MCP map, catalog, registry, README scaffold, or
runtime cache that contains canonical content rather than pointers creates competing
truth and therefore architectural drift.

### Third recovered invariant

JNL is intended to survive physical movement. The path may change; the identity must
not. This makes address stability the basis for long-form continuity and autonomous
work across branches, repositories, tools, agents, and time horizons.

## Archaeology classification

Every significant object will be assigned one of these states:

| State | Meaning |
|---|---|
| CANONICAL_AND_ACTIVE | authoritative and connected to a functioning resolution path |
| CANONICAL_BUT_DORMANT | authoritative intent remains valid, but wiring or execution is inactive |
| DERIVED_OR_MIRRORED | useful non-authoritative representation of canonical truth |
| HISTORICAL_CANON | superseded operationally but required for lineage and interpretation |
| ORPHANED | meaningful object without a complete identity, discovery, authority, or return path |
| CONTRADICTORY | object or mechanism violates another canonical authority |
| UNKNOWN | insufficient evidence; no speculative promotion |

## Central test

Every meaningful governed object should be able to answer:

```text
What am I?
Why do I exist?
What is my stable identity?
Where does my truth live?
Who holds authority over me?
What am I related to?
What state am I in?
How do I return after interruption or relocation?
```

Failure to answer one or more questions is not automatically a deletion case. It is an
archaeology finding and a candidate for repair, reclassification, or historical
preservation.

## Initial findings

1. Yggdrasil is broader than a file hierarchy. It is a governance model for world membership.
2. JD is not documentation. It is semantic routing authority: meaning plus identity plus delegation.
3. JNL is not merely a location code. It is the continuity anchor intended to survive movement.
4. LAL is a derived navigation surface and must never become a second source of truth.
5. JFS originally unified naming, identity, structure, mirroring, lifecycle, and memory horizon under one root model.
6. Several modern Grid laws appear to be descendants of these original invariants; lineage must be proven object by object rather than assumed.
7. The primary restoration risk is not missing documentation. It is duplicate authority created by later systems that solved similar problems without resolving through the original address space.
