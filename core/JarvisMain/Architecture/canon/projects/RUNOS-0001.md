# RunOS

RunOS is the governed umbrella for Raven's major projects, with priority on operating-system and runtime projects.

## Required Scope

RunOS must keep the active identity, canonical location, runtime entrypoint, status, and cross-repo references for every major project. OS/runtime projects are mandatory and may not disappear from boot, recall, audit, or project summaries.

Initial mandatory set:

- MusicOS
- BootOS
- VoiceOS
- Johnny OS
- JARVIS / Grid runtime
- every later major project designated by Raven

## Continuity Rule

A system answering about Raven's projects must consult RunOS before claiming a project is absent, inactive, minor, or unknown.

RunOS is an index and execution map, not a replacement for each project's own canon. It points to truth; it does not duplicate or flatten it.

## Runtime Rule

Boot, voice, companion, worker, audit, and rehydration paths must load or resolve RunOS so major projects remain visible across sessions, models, fleets, and repositories.

## Governing Line

> RunOS means all major projects, especially OS runtimes. MusicOS and BootOS do not get lost again.
