## What
Structured computational intelligence system — stores code as behavioral entities, each with
implementation variants, semantic intent, performance metrics, and lineage. A searchable,
rankable, evolvable atlas of algorithmic strategies. Think: GitHub meets chess rating system
for code patterns.

## Current state
- Bio defined: code as evolving population, not static artifacts
- Multi-dimensional ranking: efficiency, memory, robustness, composability, portability, clarity
- Diff-based lineage tracking: trace algorithmic development over time
- Aspirational: no code entries yet, no working database

## Directory map
- `src/` — CodeOS engine, ranking algorithm, lineage graph
- `specs/` — schema definitions, ranking methodology, entity specs
- `database/` — code entries, variants, metrics (grows over time)
- `docs/` — ranking methodology, how-to contribute, API specs
