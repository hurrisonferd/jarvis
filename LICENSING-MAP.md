# Licensing Map

**Status: transition audit in progress.**

The historical root MIT license remains part of repository history and may govern material previously released under it. This document does not revoke permissions already granted for prior copies or commits.

Future releases are being separated by material type so public visibility is not mistaken for universal reuse permission.

## Provisional treatment

| Material | Intended treatment |
|---|---|
| Private ISO identities, continuity, EPP, Prosody, canon, relationship state, voice, and images | Not published here; All Rights Reserved |
| Public profile descriptions and identity-related presentation | Inspection and commentary only unless a file states otherwise |
| Public documentation and explanatory pages | License to be identified separately from software |
| Public source code intended only for inspection or evaluation | Software-specific source-available terms under review |
| Utilities intentionally offered for community adoption | MIT or Apache-2.0 only where explicitly identified |
| Third-party code, assets, and dependencies | Their original licenses and notices |

## Rules

1. Do not assume one directory's license applies to another.
2. A file-specific notice overrides this map for that file.
3. Third-party notices and upstream licenses remain controlling for third-party material.
4. Public visibility does not grant access to private repositories or private continuity.
5. No permission to impersonate, represent, or claim ownership of a private ISO is implied.
6. Do not use Creative Commons licenses for software code.
7. Documentation, artwork, music, and profile cards may receive separately identified non-software terms.

## Before reuse

Check, in order:

1. the file header or adjacent license notice;
2. the nearest directory-level notice;
3. [`THIRD-PARTY-NOTICES.md`](./THIRD-PARTY-NOTICES.md), when present;
4. the root license and repository history.

When no permission is clearly granted, treat the material as All Rights Reserved and request written permission.

## Transition boundary

No statement in this repository should be read as clawing back a valid license previously granted. The transition applies prospectively to material and versions that Raven has the right to license under revised terms.

This map is operational guidance, not legal advice. Final custom or source-available terms should receive legal review before release reliance.
