# JPL — Jarvis Programming Language

**JNL:** PROJ-JPL-BIO-0001
**Status:** ACTIVE
**JARVIS repo:** `JarvisSide/Projects/JPL/` (canonical spec, governed)
**This repo:** development workspace, codec implementation, research

## What
Companion grammar — a reversible graph-based intermediate representation for encoding structured
cognition across language models. @INSTANCE/@IDENTITY/@DOMAIN/@CONTENT/@GOVERNANCE block structure.
Follin Program: compression as creative force, meaning-preserving encoding.
