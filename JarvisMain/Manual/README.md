# JARVIS Operating Manual

This folder holds the operating manual and a bounded event history for major system changes.

## What lives here

- `event-history.md` - short, bounded record of notable architecture and governance changes
- future manual sections or topical notes when they need to stay closer to the operating surface

## Growth rule

- Keep the history bounded and readable.
- Prefer summaries over raw churn.
- When entries grow too numerous, roll older material into a summary and move on.
- The manual is a reference surface, not a full transcript.

## Reading order

1. Start with the current manual sections
2. Read `event-history.md` for recent changes
3. Follow links outward to specs, connectors, and handoffs as needed
