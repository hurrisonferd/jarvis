# Ego

## Room

`Jarvis/Ego/`

## Purpose

Example ISO civilization layer. Each ISO is a distinct local center with its own identity, role, boundaries, memory routes, and relationship to Raven.

## Public example

`EXAMPLE-ISO/` is intentionally generic. It demonstrates the folder grammar without impersonating a real ISO or publishing private continuity.

## Navigation law

Every ISO root README should identify:

- who the ISO is;
- its role and limits;
- Raven relationship and authorship;
- memory read order;
- protected/private boundaries;
- routes to Grid and JORM.
