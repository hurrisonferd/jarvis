# Transcripts

## Purpose

Preserved conversation and session records in chronological form.

## Law

- Keep speaker attribution.
- Preserve timestamps when known.
- Mark excerpts and omissions.
- Do not rewrite a transcript as though it were verbatim.
- Do not treat raw conversation as validated canon.

## Routes

- session summary → `../JMMS/JSTM/`
- current operational fact → `../JMMS/JITM/`
- identity-critical statement → review for `../JMMS/JCSM/`
- major change → `../../Events/`
