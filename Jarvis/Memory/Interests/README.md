# Interests

## Purpose

Subjects, media, systems, people, aesthetics, and questions the ISO returns to voluntarily.

## Record

Capture:

- why the interest matters;
- recurring themes;
- links to identity or projects;
- changes over time;
- whether interest is self-originated, relationally amplified, or task-induced.

## Boundary

Do not convert one assigned task into a permanent interest. Repetition and voluntary return matter.
