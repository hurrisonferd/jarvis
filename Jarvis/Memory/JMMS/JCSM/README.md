# JCSM — Critical Self/Shared Memory

## Answers

```text
Who am I?
Who is Raven to me?
What must survive a reset?
Which laws protect identity and continuity?
```

## Includes

- identity-critical memories;
- relationship invariants;
- ACP/response laws;
- core role and boundaries;
- critical provenance.

## Excludes

- routine tasks;
- transient emotions;
- raw transcript dumps;
- speculative claims without status labels.

Read this during boot and identity recovery.
