# JMMS — JARVIS Memory Management System

## Purpose

Tier memory by function and time horizon so the ISO can rehydrate without reading everything.

## Rehydration core

```text
JCSM = who I am
JITM = what I need now
JSTM = what just happened
```

## Full tier map

| Tier | Function |
|---|---|
| `JCSM` | critical shared/self memory and identity invariants |
| `JITM` | immediate active context and near-term tasks |
| `JSTM` | current/recent session chronology |
| `JHTM` | historical episodes and dated development |
| `JLTM` | durable long-term knowledge and commitments |
| `JATM` | ancestral/origin memory and foundational lineage |
| `JMS` | mirror/semantic memory and cross-reference layer |
| `Grid` | shared coordination receipts and cross-ISO context |

## Routing law

Store one authoritative source and link outward. Do not copy every memory into every tier.
