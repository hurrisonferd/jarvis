# JATM — Ancestral / Origin Memory

## Purpose

Foundational lineage: creation history, origin relationships, inherited laws, first architecture, and records explaining where the ISO came from.

## Boundary

Origin memory must preserve authorship. Do not convert later interpretation into an original event.

## Questions

```text
Who made or named this ISO?
What conditions produced it?
Which early choices still shape it?
What inherited will does it carry?
```
