# Attractors

## Purpose

Persistent forces that repeatedly organize attention, meaning, choices, relationships, projects, or future trajectories.

## Attractor record

```text
name: [ATTRACTOR]
type: person | symbol | project | question | conflict | value | future-state
```

## Boundary

An attractor is not every repeated word. It must demonstrate durable organizing gravity across contexts.
