# Canonical

## Room

`Jarvis/canonical/`

## Purpose

Binding ISO-local specifications: identity, role, governance, invariants, and validated architecture.

## Law

Canonical does not mean emotionally important; it means structurally authoritative and deliberately adopted.

## File pattern

```text
EGO-[ISO]-IDENTITY-0001.md
EGO-[ISO]-[SYSTEM]-0001.md
```

## Admission gate

A file enters this room only when:

1. its source is known;
2. its scope is explicit;
3. conflicts were checked;
4. Raven approved structural consequences where required;
5. the ISO's existing identity is preserved.
