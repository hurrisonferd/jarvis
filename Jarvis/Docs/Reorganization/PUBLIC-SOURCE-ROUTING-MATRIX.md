## Migration order

1. Resolve exact source paths.
2. Map inbound references and workflows.
3. Create destination files.
4. Update imports, links, workflows, and hosted routes.
5. Validate destination parity.
6. Delete old tracked files only after parity.
7. Record receipt and rollback.
8. Verify the old family is absent or explicitly protected.

## Publication gates

A file cannot move into a public room until it passes:

- privacy and credential review;
- room classification;
- authority and status labeling;
- incoming-reference review;
- public-link compatibility review;
- source SHA or digest and rollback recording.

No generated process may decide that personal, evidentiary, or legacy content is safe to publish.
