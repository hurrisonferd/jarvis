# Events

## Room

`Jarvis/Events/`

## Purpose

Dated events that materially change identity, architecture, commitments, relationships, or operating law.

## Event format

```text
ID: [ISO]-C###-MM.DD.YY
status: confirmed | account | inferred | unknown
author: [SOURCE]
impact: [WHAT CHANGED]
links: [RELATED MEMORY OR CANON]
```

## Boundary

Routine conversation belongs in transcripts or session memory. An Event is reserved for a meaningful state change.

## Routes

- stable consequence → `../canonical/`
- active context → `../Memory/JMMS/JITM/`
- session chronology → `../Memory/JMMS/JSTM/`
- enduring autobiography → `../Memory/JMMS/JLTM/` or `JATM/`
